# Stop

Juego del Stop multijugador para jugar cada uno desde su móvil, sin cuentas.

- Un jugador crea la sala y comparte el enlace o el código de 4 letras.
- Sale una letra para todos a la vez; quien rellena todas las categorías puede cantar STOP.
- Se corrige en grupo y se suman los puntos (20 / 10 / 5 / 0).

Es una sola página (`index.html`). Para publicarla en Netlify: importa este repositorio, sin comando de build y con `.` como carpeta de publicación.
